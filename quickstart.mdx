## 1. Start the server

<Tabs>
  <Tab title="Docker">
    ```bash
    docker run -d --name gowa \
      -p 3000:3000 \
      -v gowa_storages:/app/storages \
      -v gowa_statics:/app/statics \
      -e APP_BASIC_AUTH=admin:changeme \
      aldinokemal2104/go-whatsapp-web-multidevice:latest
    ```

    The image's default command is `rest`, so no arguments are needed. The same image is published as `ghcr.io/aldinokemal/go-whatsapp-web-multidevice`.
  </Tab>
  <Tab title="Binary">
    Download the archive for your platform from [GitHub Releases](https://github.com/aldinokemal/go-whatsapp-web-multidevice/releases) (for example `whatsapp_9.7.0_linux_amd64.zip`), then:

    ```bash
    unzip whatsapp_9.7.0_linux_amd64.zip
    chmod +x whatsapp
    ./whatsapp rest --basic-auth=admin:changeme
    ```

    Install FFmpeg and libwebp (`cwebp`) first; GOWA uses them for media conversion.
  </Tab>
  <Tab title="From source">
    Requires Go 1.26+, FFmpeg and libwebp.

    ```bash
    git clone https://github.com/aldinokemal/go-whatsapp-web-multidevice.git
    cd go-whatsapp-web-multidevice/src
    go run . rest --basic-auth=admin:changeme
    ```
  </Tab>
</Tabs>

Check it is up:

```bash
curl http://localhost:3000/health
# OK
```

<Note>
  The default non-loopback listener requires complete `APP_BASIC_AUTH` credentials. For unauthenticated local development, bind `APP_HOST=127.0.0.1`. An authenticating reverse proxy can use the explicit `APP_ALLOW_UNAUTHENTICATED=true` override. See [authentication](/authentication).
</Note>

## 2. Create a device

Each WhatsApp account lives in a device slot. Create one and give it an ID you will reuse:

```bash
curl -u admin:changeme -X POST http://localhost:3000/devices \
  -H "Content-Type: application/json" \
  -d '{"device_id": "my-device"}'
```

Omit `device_id` to get a generated UUID.

## 3. Pair the account

<Tabs>
  <Tab title="QR code">
    ```bash
    curl -u admin:changeme http://localhost:3000/devices/my-device/login
    ```

    Open `results.qr_link` in a browser and scan it from WhatsApp → **Linked devices** → **Link a device**. The code expires after `results.qr_duration` seconds; request a new one if it lapses.
  </Tab>
  <Tab title="Pairing code">
    ```bash
    curl -u admin:changeme -X POST \
      "http://localhost:3000/devices/my-device/login/code?phone=628123456789"
    ```

    Enter `results.pair_code` on the phone under **Linked devices** → **Link with phone number instead**.
  </Tab>
  <Tab title="Dashboard">
    Open `http://localhost:3000/`, enter your Basic Auth credentials when the browser prompts, and pair the device from the UI.
  </Tab>
</Tabs>

Confirm the device is logged in (`results.is_logged_in` should be `true`):

```bash
curl -u admin:changeme http://localhost:3000/devices/my-device/status
```

## 4. Send a message

```bash
curl -u admin:changeme -X POST http://localhost:3000/send/message \
  -H "Content-Type: application/json" \
  -H "X-Device-Id: my-device" \
  -d '{"phone": "628123456789", "message": "Hello from GOWA"}'
```

```json
{
  "code": "SUCCESS",
  "message": "Success",
  "results": {
    "message_id": "3EB0B430B6F8F1D0E053AC120E0A9E5C",
    "status": "Message sent to 628123456789 (server timestamp: ...)"
  }
}
```

`phone` takes a number with country code and no `+` or spaces, or a full JID such as `628123456789@s.whatsapp.net` or `120363025246125486@g.us` for a group. With only one device registered, `X-Device-Id` is optional.

## 5. Receive messages

Restart with a webhook URL and GOWA will POST every event to it:

```bash
export WHATSAPP_WEBHOOK_SECRET="$(openssl rand -hex 32)"
./whatsapp rest --basic-auth=admin:changeme --webhook=https://example.com/wa-hook
```

Save the generated webhook secret and configure the same value on your receiver. Reuse it after restarts. See [Webhooks](/concepts/webhooks) for payloads and signature checks.
