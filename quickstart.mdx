## Prerequisites

Before you begin, make sure you have:

- Go 1.19 or higher installed
- A WhatsApp account (can be any existing WhatsApp account)
- Basic understanding of REST APIs

## Installation

<AccordionGroup>
  <Accordion icon="download" title="Download the Binary">
    Download the latest release from our GitHub repository:
    
    ```bash
    curl -L https://github.com/aldinokemal/go-whatsapp-web-multidevice/releases/latest/download/whatsapp-linux-amd64 -o whatsapp
    chmod +x whatsapp
    ```
  </Accordion>
  
  <Accordion icon="docker" title="Using Docker">
    Run the API using Docker:
    
    ```bash
    docker run -d \
      --name whatsapp-api \
      -p 3000:3000 \
      -v $(pwd)/database:/app/database \
      aldinokemal/go-whatsapp-web-multidevice:latest
    ```
  </Accordion>
  
  <Accordion icon="code" title="Build from Source">
    Clone and build from source:
    
    ```bash
    git clone https://github.com/aldinokemal/go-whatsapp-web-multidevice.git
    cd go-whatsapp-web-multidevice
    go mod tidy
    go run main.go
    ```
  </Accordion>
</AccordionGroup>

## Authentication

<Steps>
  <Step title="Start the API Server">
    Run the WhatsApp API server:
    ```bash
    ./whatsapp
    ```
    The server will start on `http://localhost:3000`
  </Step>
  
  <Step title="Login to WhatsApp">
    Open your browser and navigate to:
    ```
    http://localhost:3000/app/login
    ```
    
    You'll see a QR code. Scan it with your WhatsApp mobile app:
    1. Open WhatsApp on your phone
    2. Go to Settings → Linked Devices
    3. Tap "Link a Device" and scan the QR code
  </Step>
  
  <Step title="Verify Connection">
    Check if the connection is successful:
    ```bash
    curl http://localhost:3000/app/devices
    ```
    
    You should see your connected device in the response.
  </Step>
</Steps>

## Send Your First Message

<CodeGroup>
```bash cURL
curl -X POST http://localhost:3000/send/message \
  -H "Content-Type: application/json" \
  -d '{
    "phone": "6289685028129@s.whatsapp.net",
    "message": "Hello from WhatsApp API!"
  }'
```

```javascript JavaScript
const response = await fetch('http://localhost:3000/send/message', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    phone: '6289685028129@s.whatsapp.net',
    message: 'Hello from WhatsApp API!'
  })
});

const result = await response.json();
console.log(result);
```

```python Python
import requests

url = "http://localhost:3000/send/message"
payload = {
    "phone": "6289685028129@s.whatsapp.net",
    "message": "Hello from WhatsApp API!"
}

response = requests.post(url, json=payload)
print(response.json())
```

```go Go
package main

import (
    "bytes"
    "encoding/json"
    "fmt"
    "net/http"
)

func main() {
    url := "http://localhost:3000/send/message"
    
    payload := map[string]string{
        "phone":   "6289685028129@s.whatsapp.net",
        "message": "Hello from WhatsApp API!",
    }
    
    jsonData, _ := json.Marshal(payload)
    
    resp, err := http.Post(url, "application/json", bytes.NewBuffer(jsonData))
    if err != nil {
        fmt.Println("Error:", err)
        return
    }
    defer resp.Body.Close()
    
    fmt.Println("Message sent successfully!")
}
```
</CodeGroup>

## Common Issues

<AccordionGroup>
  <Accordion icon="triangle-exclamation" title="QR Code Not Appearing">
    If the QR code doesn't appear:
    1. Make sure the server is running on port 3000
    2. Clear your browser cache
    3. Try accessing `http://localhost:3000/app/login` directly
  </Accordion>
  
  <Accordion icon="triangle-exclamation" title="Connection Timeout">
    If you get connection timeouts:
    1. Ensure your firewall allows port 3000
    2. Check if WhatsApp Web is working in your browser
    3. Try restarting the API server
  </Accordion>
  
  <Accordion icon="triangle-exclamation" title="Message Not Delivered">
    If messages aren't being delivered:
    1. Verify the phone number format includes country code
    2. Check if the recipient is on WhatsApp using `/user/check`
    3. Ensure your WhatsApp account is not restricted
  </Accordion>
</AccordionGroup>
