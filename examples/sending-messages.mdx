## Overview

The WhatsApp API supports sending various types of messages including text, media, documents, contacts, locations, and more. This guide covers all the different message types you can send.

## Text Messages

### Basic Text Message

<CodeGroup>
```bash cURL
curl -X POST http://localhost:3000/send/message \
  -H "Content-Type: application/json" \
  -d '{
    "phone": "6289685028129@s.whatsapp.net",
    "message": "Hello! This is a test message from the API."
  }'
```

```javascript JavaScript
const response = await fetch('http://localhost:3000/send/message', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    phone: '6289685028129@s.whatsapp.net',
    message: 'Hello! This is a test message from the API.'
  })
});

const result = await response.json();
console.log('Message sent:', result);
```

```python Python
import requests

url = "http://localhost:3000/send/message"
payload = {
    "phone": "6289685028129@s.whatsapp.net",
    "message": "Hello! This is a test message from the API."
}

response = requests.post(url, json=payload)
result = response.json()
print("Message sent:", result)
```

```go Go
package main

import (
    "bytes"
    "encoding/json"
    "fmt"
    "net/http"
)

func sendTextMessage() {
    url := "http://localhost:3000/send/message"
    
    payload := map[string]string{
        "phone":   "6289685028129@s.whatsapp.net",
        "message": "Hello! This is a test message from the API.",
    }
    
    jsonData, _ := json.Marshal(payload)
    
    resp, err := http.Post(url, "application/json", bytes.NewBuffer(jsonData))
    if err != nil {
        fmt.Println("Error:", err)
        return
    }
    defer resp.Body.Close()
    
    fmt.Println("Message sent successfully!")
}
```
</CodeGroup>

## Bulk Messaging

### Send to Multiple Recipients

```javascript
const recipients = [
  '6289685028129@s.whatsapp.net',
  '6289685028130@s.whatsapp.net',
  '6289685028131@s.whatsapp.net'
];

const message = 'Hello! This is a bulk message.';

// Send messages with delay to avoid rate limiting
for (const phone of recipients) {
  try {
    const response = await fetch('http://localhost:3000/send/message', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({
        phone,
        message
      })
    });
    
    const result = await response.json();
    console.log(`Message sent to ${phone}:`, result);
    
    // Add delay between messages
    await new Promise(resolve => setTimeout(resolve, 1000));
  } catch (error) {
    console.error(`Failed to send to ${phone}:`, error);
  }
}
```

### Message Scheduling

```javascript
function scheduleMessage(phone, message, delayMs) {
  return setTimeout(async () => {
    try {
      const response = await fetch('http://localhost:3000/send/message', {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json'
        },
        body: JSON.stringify({
          phone,
          message
        })
      });
      
      console.log('Scheduled message sent:', await response.json());
    } catch (error) {
      console.error('Failed to send scheduled message:', error);
    }
  }, delayMs);
}

// Schedule a message for 1 hour later
scheduleMessage(
  '6289685028129@s.whatsapp.net',
  'This is a scheduled message!',
  60 * 60 * 1000 // 1 hour
);
```

## Error Handling

### Robust Message Sending

```javascript
async function sendMessageWithRetry(phone, message, maxRetries = 3) {
  for (let attempt = 1; attempt <= maxRetries; attempt++) {
    try {
      const response = await fetch('http://localhost:3000/send/message', {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json'
        },
        body: JSON.stringify({
          phone,
          message
        })
      });
      
      if (!response.ok) {
        throw new Error(`HTTP ${response.status}: ${response.statusText}`);
      }
      
      const result = await response.json();
      
      if (result.code === 'SUCCESS') {
        console.log('Message sent successfully:', result);
        return result;
      } else {
        throw new Error(result.message);
      }
    } catch (error) {
      console.error(`Attempt ${attempt} failed:`, error.message);
      
      if (attempt === maxRetries) {
        throw new Error(`Failed to send message after ${maxRetries} attempts: ${error.message}`);
      }
      
      // Wait before retry (exponential backoff)
      await new Promise(resolve => setTimeout(resolve, Math.pow(2, attempt) * 1000));
    }
  }
}

// Usage
try {
  await sendMessageWithRetry('6289685028129@s.whatsapp.net', 'Hello World!');
} catch (error) {
  console.error('Failed to send message:', error);
}
```

## Best Practices

<AccordionGroup>
  <Accordion icon="clock" title="Rate Limiting">
    - Add delays between messages (minimum 1 second)
    - Monitor rate limit headers in responses
    - Implement exponential backoff for retries
    - Use bulk messaging queues for large volumes
  </Accordion>
  
  <Accordion icon="shield" title="Message Validation">
    - Always validate phone numbers before sending
    - Check message length limits (4096 characters for text)
    - Verify media file sizes and formats
    - Sanitize user input to prevent injection
  </Accordion>
  
  <Accordion icon="users" title="User Experience">
    - Use typing indicators for better UX
    - Send media with descriptive captions
    - Structure long messages with line breaks
    - Use emojis sparingly for emphasis
  </Accordion>
  
  <Accordion icon="chart-line" title="Monitoring">
    - Log all message attempts and results
    - Track delivery rates and failures
    - Monitor API response times
    - Set up alerts for high failure rates
  </Accordion>
</AccordionGroup>
