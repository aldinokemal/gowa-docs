GOWA ([go-whatsapp-web-multidevice](https://github.com/aldinokemal/go-whatsapp-web-multidevice)) is a self-hosted server that links to WhatsApp as a companion device, the same way WhatsApp Web does, and exposes it over HTTP. It is a single Go binary (`whatsapp rest`) built on [whatsmeow](https://github.com/tulir/whatsmeow). These docs track **v9.7.0**.

<Warning>
  GOWA is an unofficial client. It is not affiliated with WhatsApp or Meta, and using it can get a number restricted or banned. Do not use it for spam or bulk unsolicited messaging.
</Warning>

## What one server gives you

<CardGroup cols={2}>
  <Card title="Multiple accounts" icon="users" href="/concepts/multidevice">
    Run several WhatsApp numbers on one server. Each is a device slot, selected per request with `X-Device-Id`.
  </Card>
  <Card title="REST API" icon="code" href="/api-reference/introduction">
    Send text, media, polls, locations and contacts. Manage chats, groups, newsletters and your profile.
  </Card>
  <Card title="Webhooks" icon="webhook" href="/concepts/webhooks">
    Signed HTTP callbacks for messages, receipts, reactions, group, call and newsletter events.
  </Card>
  <Card title="Scheduled sends" icon="clock" href="/examples/scheduled-sends">
    Send any message later, once or on a daily, weekly or monthly repeat.
  </Card>
  <Card title="MCP server" icon="robot" href="/integrations/mcp">
    Streamable-HTTP MCP endpoint at `/mcp` so AI agents can send and read messages.
  </Card>
  <Card title="Chatwoot" icon="headset" href="/integrations/chatwoot">
    Mirror WhatsApp conversations into a Chatwoot inbox and reply from Chatwoot.
  </Card>
</CardGroup>

A web dashboard ([gowa-ui](https://github.com/aldinokemal/gowa-ui)) is served at `/` for pairing devices and trying the API by hand.

## Get started

<Steps>
  <Step title="Run GOWA">
    Start it with Docker or a release binary. See the [Quickstart](/quickstart).
  </Step>
  <Step title="Create a device and pair it">
    `POST /devices`, then scan the QR code or use a pairing code. See [Authentication](/authentication).
  </Step>
  <Step title="Send a message">
    `POST /send/message` with Basic Auth and `X-Device-Id`.
  </Step>
  <Step title="Receive events">
    Point `WHATSAPP_WEBHOOK` at your endpoint. See [Webhooks](/concepts/webhooks).
  </Step>
</Steps>

## Not included

- **Official SDKs.** There are none. Call the HTTP API directly (see [Client examples](/api-reference/sdks/go)) or generate a client from the [OpenAPI spec](https://github.com/aldinokemal/go-whatsapp-web-multidevice/blob/main/docs/openapi.yaml). A community n8n node exists: [`@aldinokemal2104/n8n-nodes-gowa`](https://www.npmjs.com/package/@aldinokemal2104/n8n-nodes-gowa).
- **Rate limiting.** GOWA does not throttle requests. See [Sending limits](/advanced/rate-limiting).
