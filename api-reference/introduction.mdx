## Overview

The WhatsApp API MultiDevice provides a comprehensive REST API for sending and receiving WhatsApp messages programmatically. Built on the WhatsApp Web MultiDevice protocol, it offers reliable messaging capabilities for businesses and developers.

## Base URL

All API requests should be made to:

```
http://localhost:3000
```

## Quick Start

<Steps>
  <Step title="Start the API Server">
    Run the WhatsApp API server on your local machine or server.
  </Step>
  
  <Step title="Authenticate with WhatsApp">
    Use QR code or pairing code to link your WhatsApp account.
  </Step>
  
  <Step title="Send Your First Message">

  </Step>

## Authentication

### WhatsApp Authentication

Before using the API, you must authenticate with WhatsApp:

1. **QR Code Method**: Navigate to `/app/login` and scan the QR code
2. **Pairing Code Method**: Use `/app/login-with-code` with your phone number

### API Security

The API supports multiple authentication methods:

<Tabs>
  <Tab title="Basic Auth">
    ```bash
    curl -X POST http://localhost:3000/send/message \
      -u "username:password" \
      -H "Content-Type: application/json" \
      -d '{"phone": "6289685028129@s.whatsapp.net", "message": "Hello"}'
    ```
  </Tab>
  
  <Tab title="API Key">
    ```bash
    curl -X POST http://localhost:3000/send/message \
      -H "X-API-Key: your-api-key" \
      -H "Content-Type: application/json" \
      -d '{"phone": "6289685028129@s.whatsapp.net", "message": "Hello"}'
    ```
  </Tab>
  
  <Tab title="No Auth (Development)">
    ```bash
    curl -X POST http://localhost:3000/send/message \
      -H "Content-Type: application/json" \
      -d '{"phone": "6289685028129@s.whatsapp.net", "message": "Hello"}'
    ```
  </Tab>
</Tabs>

## API Endpoints Overview

### Application Management
- `GET /app/login` - Get QR code for authentication
- `GET /app/login-with-code` - Get pairing code for authentication
- `GET /app/logout` - Logout and remove session
- `GET /app/reconnect` - Reconnect to WhatsApp
- `GET /app/devices` - Get list of connected devices

### User Operations
- `GET /user/info` - Get user information
- `GET /user/avatar` - Get user avatar
- `POST /user/avatar` - Update user avatar
- `POST /user/pushname` - Update display name
- `GET /user/my/privacy` - Get privacy settings
- `GET /user/my/groups` - Get user's groups
- `GET /user/my/contacts` - Get contact list
- `GET /user/check` - Check if user is on WhatsApp
- `GET /user/business-profile` - Get business profile

### Message Operations
- `POST /send/message` - Send text message
- `POST /send/image` - Send image
- `POST /send/audio` - Send audio file
- `POST /send/file` - Send document
- `POST /send/video` - Send video
- `POST /send/contact` - Send contact
- `POST /send/link` - Send link with preview
- `POST /send/location` - Send location
- `POST /send/poll` - Send poll/vote
- `POST /send/presence` - Update presence status
- `POST /send/chat-presence` - Send typing indicator

### Message Management
- `POST /message/{id}/revoke` - Revoke/delete message
- `POST /message/{id}/delete` - Delete message
- `POST /message/{id}/reaction` - React to message
- `POST /message/{id}/update` - Edit message
- `POST /message/{id}/read` - Mark message as read
- `POST /message/{id}/star` - Star message
- `POST /message/{id}/unstar` - Unstar message

### Chat Operations
- `GET /chats` - List all chats
- `GET /chat/{jid}/messages` - Get chat messages
- `POST /chat/{jid}/label` - Label/unlabel chat
- `POST /chat/{jid}/pin` - Pin/unpin chat

### Group Management
- `GET /group/info` - Get group information
- `POST /group` - Create new group
- `POST /group/participants` - Add participants
- `POST /group/participants/remove` - Remove participants
- `POST /group/participants/promote` - Promote to admin
- `POST /group/participants/demote` - Demote from admin
- `POST /group/join-with-link` - Join group via link
- `GET /group/info-from-link` - Get group info from link
- `GET /group/participant-requests` - Get join requests
- `POST /group/participant-requests/approve` - Approve join request
- `POST /group/participant-requests/reject` - Reject join request
- `POST /group/leave` - Leave group
- `POST /group/photo` - Set group photo
- `POST /group/name` - Set group name
- `POST /group/locked` - Lock/unlock group
- `POST /group/announce` - Enable/disable announce mode
- `POST /group/topic` - Set group topic

### Newsletter Operations
- `POST /newsletter/unfollow` - Unfollow newsletter

## Response Format

All API responses follow a consistent format:

```json
{
  "code": "SUCCESS",
  "message": "Description of the result",
  "results": {
    // Response data here
  }
}
```

### Success Response
```json
{
  "code": "SUCCESS",
  "message": "Message sent successfully",
  "results": {
    "message_id": "3EB0B430B6F8F1D0E053AC120E0A9E5C",
    "status": "Message sent to 6289685028129@s.whatsapp.net"
  }
}
```

### Error Response
```json
{
  "code": "INTERNAL_SERVER_ERROR",
  "message": "you are not logged in",
  "results": null
}
```

## Phone Number Format

All phone numbers must include the country code and use the WhatsApp JID format:

- **Format**: `{country_code}{phone_number}@s.whatsapp.net`
- **Example**: `6289685028129@s.whatsapp.net`
- **Group Format**: `{group_id}@g.us`

<Note>
Remove any leading zeros, plus signs, or special characters from phone numbers.
</Note>

## Rate Limiting

The API implements rate limiting to comply with WhatsApp's usage policies:

- **Messages**: 1000 messages per day per number
- **API Calls**: 100 requests per minute
- **File Uploads**: 50 files per hour

Rate limit headers are included in responses:

```http
X-RateLimit-Limit: 100
X-RateLimit-Remaining: 95
X-RateLimit-Reset: 1640995200
```

## Media Handling

### Supported Formats

| Type | Formats | Max Size |
|------|---------|----------|
| **Images** | JPG, PNG, GIF, WebP | 16 MB |
| **Videos** | MP4, 3GP, MOV, AVI | 64 MB |
| **Audio** | MP3, OGG, AAC, M4A | 16 MB |
| **Documents** | PDF, DOC, XLS, TXT | 100 MB |

### Upload Methods

<Tabs>
  <Tab title="File Upload">
    ```bash
    curl -X POST http://localhost:3000/send/image \
      -F "phone=6289685028129@s.whatsapp.net" \
      -F "caption=Check out this image!" \
      -F "image=@/path/to/image.jpg"
    ```
  </Tab>
  
  <Tab title="URL Upload">
    ```bash
    curl -X POST http://localhost:3000/send/image \
      -H "Content-Type: application/json" \
      -d '{
        "phone": "6289685028129@s.whatsapp.net",
        "caption": "Image from URL",
        "image_url": "https://example.com/image.jpg"
      }'
    ```
  </Tab>
</Tabs>

## Error Codes

| Code | Description | Action |
|------|-------------|---------|
| `SUCCESS` | Request completed successfully | Continue |
| `400` | Bad request - invalid parameters | Check request format |
| `401` | Unauthorized - not logged in | Authenticate with WhatsApp |
| `404` | Not found - invalid endpoint or resource | Check URL and parameters |
| `429` | Too many requests - rate limited | Reduce request frequency |
| `500` | Internal server error | Check server logs |
