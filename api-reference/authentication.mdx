GOWA supports **HTTP Basic Auth** and nothing else: there are no API keys, bearer tokens or JWTs for the REST API. (MCP can additionally accept OAuth tokens; see [MCP server](/integrations/mcp#remote-clients-with-oauth).)

## Configure

```bash
APP_BASIC_AUTH=admin:changeme,ops:another-password   # or --basic-auth=admin:changeme
```

Each comma-separated `user:pass` pair is a valid login. Every entry must contain both a username and password. A non-loopback listener refuses to start without complete credentials. Bind `APP_HOST=127.0.0.1` for unauthenticated local development. Use `APP_ALLOW_UNAUTHENTICATED=true` only when a reverse proxy authenticates callers and direct access to GOWA is restricted.

## Send credentials

<CodeGroup>
```bash curl
curl -u admin:changeme -H "X-Device-Id: my-device" \
  http://localhost:3000/app/devices
```

```bash Header
curl -H "Authorization: Basic $(echo -n 'admin:changeme' | base64)" \
  -H "X-Device-Id: my-device" \
  http://localhost:3000/app/devices
```

```javascript JavaScript
const res = await fetch("http://localhost:3000/user/my/groups", {
  headers: {
    Authorization: "Basic " + Buffer.from("admin:changeme").toString("base64"),
    "X-Device-Id": "my-device",
  },
});
```

```python Python
import requests
r = requests.get("http://localhost:3000/user/my/groups",
                 auth=("admin", "changeme"),
                 headers={"X-Device-Id": "my-device"})
```
</CodeGroup>

Wrong or missing credentials return `401 Unauthorized`.

## Public routes

| Route | Why |
| --- | --- |
| `/health` | Liveness checks. |
| `/statics/*` | QR images and media files. Known URLs remain public. Non-image uploads download as attachments. Protect access at your proxy if needed. |
| `/chatwoot/webhook`, `/chatwoot/webhook/{device_id}` | Called by Chatwoot; secured by `CHATWOOT_WEBHOOK_SECRET`. |
| MCP OAuth endpoints and `/.well-known/*` metadata | OAuth flow, when enabled. |

## WebSocket

Browsers cannot set headers on WebSocket connections, so `/ws` also accepts `/ws?device_id=my-device&authorization=<base64 user:pass>`. Use `wss://` and redact credentials from proxy logs.

The WebSocket and state-changing HTTP routes reject untrusted browser origins. Set the dashboard's exact origin in `APP_TRUSTED_ORIGINS` or `APP_CORS_ALLOWED_ORIGINS`. A wildcard CORS origin does not grant this access, and `null` origins from `file://` pages are rejected. HTTP mutations from an untrusted origin return `403 CROSS_SITE_REQUEST_BLOCKED`. See [browser access configuration](/authentication#cors).

## Device header

Basic Auth identifies the API caller, not the WhatsApp account. Every device-scoped call also needs `X-Device-Id` when more than one device exists. See [Multi-device](/concepts/multidevice).

<Warning>
  Basic Auth sends credentials on every request. Always use HTTPS in front of GOWA outside a trusted network.
</Warning>
