---
title: "Rate Limits"
description: "The GOWA API has no request rate limits; WhatsApp's own limits still apply."
---

The GOWA API **does not rate-limit requests** and returns no `X-RateLimit-*` headers. Requests go straight to WhatsApp.

Limits that do apply:

| Limit | Value |
| --- | --- |
| Request timeout | 45 s → `504 GATEWAY_TIMEOUT` |
| Request body | 100 MB |
| Uploads | Image 20 MB, document 50 MB, video 100 MB |

WhatsApp restricts accounts that send too much or to people who did not write first. The only signal GOWA passes through is `429 WA_REACHOUT_TIMELOCK`, a temporary block on starting new chats.

See [Sending limits](/advanced/rate-limiting) for pacing guidance and how to add limits at your reverse proxy.
